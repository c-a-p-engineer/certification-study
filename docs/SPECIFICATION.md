# CERTIFICATION//OVERDRIVE — 仕様書

**状態:** 現行実装を基準とする公開アプリの機能仕様。更新日: 2026-10-24。
**対象:** [AWS SAA-C03 向け学習アプリ](https://c-a-p-engineer.github.io/certification-study/)。
**管理:** `AGENTS.md` が変更時の同期手順を所有し、この文書が利用者から見た動作と受入条件を所有する。README は概要と入口であり、この仕様の複製ではない。

## 1. 目的と適用範囲

- オリジナルのAWS SAA練習問題と反復学習・模擬試験・設計判断の練習を、ゲームとして継続しやすくする。
- スマートフォン（320/360/400pxを含む狭い幅）で初回の行動をすぐ選べる。
- XP、モンスター討伐、称号は学習の動機づけであり、AWS認定合格率・公式スコアを示さない。
- 学習記録は端末内で保持する。サーバー同期、アカウント、オンラインLeaderboard、自動外部送信は対象外。

## 2. ホーム（初期画面）の情報設計

### 常に表示するもの

1. アプリ名・ランク・設定へのメニュー。
2. 現在の称号とレベル進捗。
3. 保存済み学習・模擬試験があれば、その再開導線。
4. **「今日の5分クエスト」**を明瞭な最優先学習アクションとして表示し、実行可能条件と問題数・出題理由を示す。
5. **「START MISSION」**（標準学習）と弱点復習の入口。
6. 本日のDAILY QUEST報酬状況、XP・正答率・復習期限・ベストコンボのコンパクトな進捗表示、オフライン状態。

### 初期状態では閉じるもの

| 開閉パネル | 内包する機能 | 表示条件 |
| --- | --- | --- |
| 問題数・分野・模擬試験などを選ぶ | 分野、10/20/無制限、65問模擬試験、シナリオ問題、能動想起、復習、ボス選択 | ホーム上で任意に展開 |
| 冒険・設計チャレンジ | モンスター、5遠征、AWS設計シミュレーター | 任意に展開 |
| もっと学習する | RECALL RAID、SMART QUEST、BOSS RUSH | 任意に展開 |
| 学習記録・成長分析 | 学習タイムライン、成長グラフ、学習分析 | 任意に展開 |
| スキル・コレクション | スキルツリー、レリック、習熟度、問題カバレッジ | 任意に展開 |

- 各パネルはネイティブの `details/summary` でキーボードからも展開可能とし、画面幅やJavaScriptの追加状態保存に依存しない。
- 閉じているパネルは、長大なコンテンツを初期スクロール上へ露出させない。パネルを開けば従来の各機能を利用できる。
- 隠したパネルの機能を削除しない。標準学習・5分クエスト・復旧の導線は隠さない。
- ホーム表示変更のみでXP・問題ID・進捗・保存schemaの意味を変えない。
- 視覚効果削減設定を尊重する。開閉には予測不能な報酬やゲーム強制遷移を追加しない。

## 3. 学習セッション

- 問題バンクは **348問**、うち長めのシナリオ形式 **48問**。4分野（セキュリティ・耐障害性・パフォーマンス・コスト最適化）。選択肢順序はセッション内でシャッフルし、複数選択は正解集合との完全一致で採点する。
- 通常学習は分野選択、10問・20問・無制限の出題数を提供する。間違い復習とシナリオ限定学習も提供する。
- `今日の5分クエスト` は最大5問の任意セッション。期限到来した前日以前の復習、過去の誤答、未学習を基準に重複IDなしで選び、対象が足りなければ実問数を示す。完了後に明確な終了操作があり、自動的に次のセッションを開始しない。
- 65問模擬試験は130分の制限時間を持ち、演習とは採点・履歴・経験値を分離する。後から1問ずつ解説とAWS公式参照を確認できる。
- 用語解説には読み方・説明を含め、必要時に展開できる。読みやすさのため文字サイズとフォーカス表示を変更できる。

## 4. 学習効果と報酬

- `applyStudyAttempt` は副作用のない解答トランザクションを提供する。保存済みrunIdと最大1024件のreceiptにより同一解答イベントの再加算を防ぐ。
- 同じ暦日の同じ問題への再正解は基本XP・敵ダメージを加算せず、正解復習連続回数を伸ばさない。模擬試験の解答は訓練XP・敵HP・日次報酬・訓練復習予定を更新しない。既存XPの遡及変更はしない。
- 5種類の分野別遠征、9種の敵とNG+、8件×各3段階の設計判断演習は任意のゲーム/学習モード。実力認定や公式AWSの審査と混同しない。
- 間隔復習とRETENTION LABの1/3/7/14日統計は、日付付き実観測とサンプル数を示す。未計測期間を補完したり、合格確率や学習効果の因果を断定したりしない。
- 問題の独立した有識者承認は現時点で **0/348件**。AWS公式資料へのリンク、AI生成の解説、既存の編集日付は独立承認の代わりにならない。

### OVERDRIVE 7.3：アーキテクチャ判断の再演習

- 既存4ケースに、リージョンDR（RTO/RPO）、S3のストレージ階層、OrganizationsのSCP/IAM、Lambda + SQSの失敗処理を加え、計8ケース・各3判断とする。
- 各判断は3択、要件・根拠・選択肢別フィードバック・AWS公式参照を提供する。概念図は要素一覧であり、通信順序や正確なトポロジーを主張しない。
- ケース終了時に誤ったstep IDを `designLab.reviewDue` の最大40件の任意ローカル記録へ保持し、次の**ローカル暦日**から設計ラボに**対象stepだけの単問復習**を表示する。単問復習では通常の3ステップケース完成記録・ベスト成績・勲章を更新しない。正しく再判断したstepはリストから除外し、同じstepの未修得記録は1件に集約する。
- `caseId:stepId` が出所を識別する。これは**設計演習専用の復習予定**であり、348問の通常の質問ID、review scheduling、通常XP、模試成績を変更しない。過去の設計記録に誤答履歴が無い場合は復元・推測しない。
- v1/v2バックアップに既存 `designLab` の追加任意フィールドを含められ、保存入力時には出所・件数・step有効性を確認する。実デバイスE2Eと独立有識者レビューは未完了。

### OVERDRIVE 7.2：任意の遠征チェーン・収集

- 既存の5遠征（各5問）に、問題のindexと同じ5段階の進行表示（索敵・遭遇・対策・反撃・決戦）を付ける。既存v1 missionの保存indexから自動再現でき、新しい進捗キーを導入しない。
- 遠征でのみ敵SVGと次の設計観点を示す。集中表示では非表示、320px級画面でも回答領域を圧迫しない。演出に追加のランダム性・待機時間・報酬倍率を導入しない。
- 収集段階は（1）異なる探索先1つクリア、（2）異なる探索先3つクリア、（3）全5つクリア＋翌日以降の復習成功から獲得したレアエンブレム2種、の証跡から導出する。周回回数だけではレア報酬は増えず、追加XPも与えない。
- このコレクションはクリア履歴からの派生表示で、保存データの形式を変更しない。遠征が苦手なら利用しなくても通常学習・5分クエストを使える。

## 5. ローカルデータ・復旧

- progress、日付付き回答履歴、学習セッション、模試の途中状態等はブラウザのローカル領域に保存される。
- v1/v2 JSONバックアップの互換インポートとv2 SHA-256破損検出（署名ではない）を維持し、復元処理のjournalが残れば自動保存を止めて元データを守る。
- 複数タブで外部変更を検出した場合、古いタブの自動保存を停止し、機密を含むJSON退避と最新記録の再読込を案内する。Web Locksが利用できる場合に限り協調する書込を直列化する。非対応環境で原子的な競合排除は保証しない。
- ブラウザのキャッシュ削除やデータ消去を復旧の既定策にしない。
- PWAのキャッシュ後はオフラインで出題可能。ただし外部AWSドキュメントはオフラインで提供されない。

## 6. アクセシビリティと表示

- Android/Braveなどのモバイル閲覧を想定し、320px幅までの狭い画面で横溢れを抑え、学習問題・回答の可読性を優先する。
- 開閉操作・解答・次へ・メニューにキーボードで到達できる。操作可能要素のタップ領域は原則44px以上とし、focus-visibleとreduced motionを維持する。
- ホームの開閉によってクイズの読込や採点、セッション復帰に影響を与えない。

**検証の境界:** CI成功は静的テスト・ビルドの成功であり、物理Android端末や実ブラウザE2Eでの操作を証明しない。これらは現在保留中。

### コンポーネント境界（2026-10-24）

- `src/main.tsx` は画面遷移・解答状態と保存処理のオーケストレーションを保持する。
- `src/StudyQuestionIntro.tsx` は問題本文、選出理由、読み付き用語ガイドの表示のみを担当し、採点や保存を実行しない。
- `src/HomeProgressSummary.tsx` は既存のXP・累積正答率・復習期限・コンボ数を受け取り表示するだけで、学習状態を更新しない。
- 模試の解答レビューは引き続き `src/ExamReviewPanel.tsx` で読み取り専用とする。
- `src/ResultOverview.tsx` は採点済み結果の点数・練習用ランク評価を表示するだけとし、模試XP・保存・試験合否の再計算を行わない。評価詳細や報酬の実際の更新は既存の状態管理が責任を持つ。
