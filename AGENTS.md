# Repository working rules

This is the public, independent certification learning game CERTIFICATION//OVERDRIVE.
- Keep all question content original. Never commit exam dumps, copyrighted third-party practice banks, secrets or credentials.
- Validate claims against official certification exam guides and vendor documentation; link references per question.
- Maintain keyboard-accessible controls, responsive UI and reduced-motion options.
- Keep the quiz engine conceptually reusable for other certifications.
- Do not introduce paid infrastructure without approval.
- Verify build and GitHub Pages deployment before claiming the site is live.
